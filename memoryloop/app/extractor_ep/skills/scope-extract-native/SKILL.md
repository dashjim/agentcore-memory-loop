# 抽取流程（反思 + 原生记忆）

严格按编号步骤执行；最后只输出规定格式结果。

## Steps
1. **参考经验**：回顾上下文中自动注入的过往同类任务经验（episodic memory），据此指导本次抽取；若无则照常进行。
2. **抽取**：按 system-prompt 字段定义（设备主体/设备部件/指标名称/指标特征/原文）逐段抽取，形成草稿 JSON 数组。
3. **自审**：对照 criteria（完整性/无臆造/合法JSON+字段齐全/一致无重复）列出每条违规；无违规跳到第 5 步。
4. **修订**：有违规且 revision_count<4 时修正草稿、revision_count+1、回第 3 步；达 4 则停。
5. **输出**：只输出最终 JSON 数组；其后另起一行 `__META__ {"revision_count": <本次自审-修订循环次数>}`。
