# SCOPE 抽取流程（自我进化）

你要从给定的工业技术文档 Markdown 中抽取结构化记录。**严格按下列编号步骤执行**，把推理过程和每一步的产出写清楚，最后只输出规定格式的结果。

## Steps

1. **回忆经验（recall）**
   - 调用 `recall_lessons(scope="strat")` 取跨文档通用规则（战略记忆）。
   - 调用 `recall_lessons(scope="tact")` 取与当前文档相关的即时技巧（战术记忆）。
   - 把返回的每一条规则读入工作上下文，抽取时逐条应用。若无返回则照常进行。

2. **抽取（extract）**
   - 逐段通读文档，按 system-prompt 的字段定义抽取记录：`设备主体 / 设备部件 / 指标名称 / 指标特征 / 原文`。
   - 一个部件的多个指标各成一条记录。应用第 1 步回忆到的所有规则。
   - 形成草稿 JSON 数组。

3. **自我审查（self-critique）**
   - 对照以下 criteria 逐项检查草稿，列出**每一条违规**：
     - a. **完整性**：是否有明显的技术要求/参数被漏抽？设备主体是否识别正确？
     - b. **无臆造**：每条记录的信息是否都能在原文中找到？`原文` 是否真实对应？
     - c. **格式**：是否为合法 JSON 数组？字段是否齐全、无空必填？数值格式是否遵循已知规则？
     - d. **一致性**：同一部件/指标的表述是否一致？有无重复条目？
   - 如果没有任何违规，跳到第 5 步。

4. **修订（revise）**
   - 若存在违规且当前修订次数 `revision_count < 4`：针对每条违规修正草稿，`revision_count` 加 1，**回到第 3 步**重新自审。
   - 若 `revision_count` 已达 4：停止修订，继续第 5 步（并在结果中标注仍存疑之处）。

5. **沉淀经验（reflect & record）**
   - 反思本次抽取：哪些经验**可跨文档复用**（如"日期统一 YYYY-MM-DD""口径写作 DN×壁厚，如 48.3×3.6""同一部件多指标应拆多条"）→ 调 `record_lesson(scope="strat", text=...)`。
   - 哪些是**仅对当前文档**有用的技巧（如"本文档设备主体为 150m³ 液氮储罐""表格在 page_11"）→ 调 `record_lesson(scope="tact", text=...)`。
   - 每条经验单独调用一次，文字精炼、可操作。

6. **输出（output）**
   - 只输出最终 JSON 数组（无解释文字）。
   - 在 JSON 之后，另起一行输出一行元信息：`__META__ {"revision_count": <本次自审-修订循环发生的次数>}`，供外层采集反思轮数。
