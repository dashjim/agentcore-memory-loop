WHY记忆能让 Agent 越跑越好吗

一个所有做 Agent 的人都会问的问题

给 agent 加长期记忆，它会不会「越用越聪明」？用可测量的方式回答，并给出最佳实践。
直觉

记忆 = 自学习

把过去经验记下、下次复用，agent 应该越跑越好。几乎所有人的默认假设。

现实

没那么简单

第一版「看起来」验证了直觉——但那是评分 bug 的假象。修正后增益消失。

真相

关键在存什么

记忆能变好多少，取决于往里存什么；而能存到「该抽什么」这类关键反馈，取决于有没有 oracle。

主线：记忆机制是好的。没 oracle 时，靠对照原文的自我批评它也能救回一部分漏项（无标准答案也救回 4–10 条）；但只做抽象自省，够不着「该抽什么」这类关键问题。一旦存进 oracle 质量的反馈，同一套机制立刻突飞猛进（试金石 1/7 → 7/7）。

问题一 · 评分 bug

裁判会重复计分

分块打分缺全局约束，同一抽取项被重复算去匹配多条 GT，系统性高估覆盖率。

铁证：某次只抽 91 条，却报匹配 94 条 GT——94>91 一对一不可能。

问题二 · 对比混淆

比的不是同一个东西

那个「好」的记忆模式偷偷用了更强的抽取器，还没冷启动。

它冷启动（记忆还空着）就已领先——领先跟记忆无关。

修好评分 + 拉平变量 + 冷启动重跑后：记忆增益消失。教训一：先怀疑自己的尺子——没校准的乐观结果比没有结果更危险。

DIAGNOSIS为什么没用

不下「记忆无效」的结论，先做错误分析

把漏抽的 GT 全捞出来分类：约 3/4 是「真召回失败」——根本没抽出来。这些漏项高度同质。
漏项长什么样

都不是「指标+数值」

  • 「外观颜色及喷涂 LOGO 须与甲方确认」
  • 「真空度测量报告 / 真空度测量要求」
  • 「外部油漆等工序」
  • 「承制单位细化设计…提供全套地脚螺栓」

全是散文式、流程式、待确认类要求。

根因

schema 让模型「以为不该抽」

抽取 schema 天生面向定量指标。模型看到没有数值、只有要求的话，就默认「这不是一条指标」直接跳过。

漏的不是模型能力，是它以为这些不该抽。

教训二：「没效果」往往不是终点，而是一个还没做的错误分析。不做归因，就会把「任务定义问题」误判成「方法无效」。

ORACLE决定成败的那个概念

什么是 Oracle，为什么是它说了算

Oracle（判定源）= 能告诉 agent「对不对 / 该抽什么」的外部权威。核心：它提供的信息，从输入本身推不出来，必须外部给。
oracle 形式告诉 agent 什么
标准答案 (GT)这篇「应该」抽出哪些
人类反馈「这类也要抽」/「这条错了」
大模型对比 GT/规范检查按规范判对错、漏了哪类
下游验证参数拿去用报错 → 抽错了

标准答案只是其中一种；后三种在真实系统里很常见。

任务规格类教训

该抽什么/粒度/什么算一条——必须 oracle。从「文档+自己输出」推不出。本实验决定成败的就是这类。

源覆盖/一致性类教训

漏了原文里的X/重复/格式错——对照原文即可，无 oracle 也能学一点（天花板低）。

记忆不产生新知识，它只搬运。搬运什么，取决于回路里的 oracle。

BEST PRACTICE记忆使用的最佳实践

怎么用记忆，才能真的越跑越好

记忆负责「捕获并复用」反馈，反馈本身必须由 oracle 提供。落到工程上四条。
01

先确保回路里有 oracle

没有「对错/目标」的外部信号，记忆再多也原地打转。oracle 不必是完整 GT——一次人类纠正、少量标注、带 rubric 的裁判都行。博客 self-learning 有效正因它吃人类/下游反馈。

02

存「具体批评」，别存「抽象规则」

「你漏了真空度测量这一段」有用；「复合指标要拆分」空洞，还诱发过度拆分反噬。记忆要对照答案/原文，指名道姓。

03

oracle 可以只用一次

用少量 GT 做一次错误分析，把结论沉淀成可复用记忆，之后无标注地跑。用少量监督撬动长期收益，最划算。

04

分清想学哪类教训

任务规格类必须 oracle；源覆盖/一致性类对照原文即可，无 oracle 也能学一点（天花板低）。

LIMITS & TAKEAWAY诚实局限 · 一句话带走

能说什么，不能说什么

结论方向可信，但边界要讲清——这也是「诚实实验」的一部分。
能说
  • 记忆注入机制有效（实验 C 证明）
  • 瓶颈是记忆内容质量，取决于 oracle
  • 用 GT/人类/大模型反馈都能兑现增益
  • 提示词/schema 是漏抽的真因，改得动
不能说 / 局限
  • 单文档、小样本、高方差(覆盖率 0.55–0.81 跳动)→幅度不强断
  • 泛化未测(未做留出文档评估)
  • 裁判未经人工校准；有测量口径背离
  • 需多文档盲测+多seed+CI 严格验证
记忆能让 agent 越跑越好——但前提是回路里有 oracle 把「对错/该抽什么」喂进来。
记忆负责捕获并复用反馈；它是好的载体，不是好的老师。
