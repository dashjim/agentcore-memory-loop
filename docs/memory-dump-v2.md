## 一、custom V2 canonical 规则集（consolidation 合并后的**唯一**一份，13 条）

1. **设备主体识别规则**：以文档标题或首行出现的"容量+介质+设备类型"组合（如"XXm³液氮储罐"）作为设备主体标识，统一填入所有子条目的"设备主体"字段。

2. **部件拆分规则**：同一原文句中并列描述多个部件的同类指标时（如"上进液管通径DN40、下进液管通径DN80"），须按部件逐条拆分为独立记录，不得合并。

3. **复合指标拆分规则**：同一部件的同一原文若同时包含多个不同类型指标（如规格+数量、通径+压力），须按指标类型逐条拆分，每条仅含一个指标名称与对应特征值。

4. **规格与数量分离规则**：阀门、仪表、紧固件等部件清单中，规格（DN/PN/英寸/型号）与数量（台/套/支）须分别作为独立指标条目抽取；附件信息（如配套法兰、紧固件、螺母/垫圈）亦须单独列为独立条目，不得与主体规格合并。

5. **管口接管参数拆分规则**：管口/接管参数须同时抽取通径（DN值或Φ×壁厚规格）与压力等级；若原文同时给出两者，须拆分为独立指标条目；仅有通径时单独成条，不强行补全压力。

6. **材料分层抽取规则**：材料描述涉及多个部件（如外罐、内罐、管道、阀门）时，须按部件分别建立独立条目；即便同一句话描述多个部件材质相同，仍须拆分，部件字段各自填写，不得将多部件材料合并为一条。

7. **设备本体核心参数抽取规则**：按"介质名称—几何容积—充满率—最高工作压力—设计压力—设计温度—绝热形式—安装形式"顺序逐项独立成条，缺一不可；性能指标（如静态蒸发率、真空寿命等）须完整保留"≤""≥""不少于""不高于"等限定符号与数值、单位，准确反映约束方向，不得省略。

8. **工作环境参数抽取规则**：安装地点的气象、地震等环境参数统一归入"工作环境"部件下逐条抽取，须完整覆盖温度（历年月均最低/最高、年极端最低/最高）、风（平均风速、瞬时最大风速、基本风压）、雪（基本雪压）、地震（设防烈度及加速度值）四类要素，每项独立成条。

9. **焊接与检测标准完整保留规则**：焊接检测要求中，须区分焊缝类别（A/B类、C/D/E类）与检测方法（RT/PT/UT），同一焊缝类别若同时涉及多种检测方法须分别抽取为独立条目；每条须完整保留执行标准（含年份的标准编号）、技术等级（如AB级）、合格级别（如Ⅰ/Ⅱ级）、检测比例（如100%），不得省略任一要素。

10. **清洁度与表面处理要求完整保留规则**：清洁度/表面处理要求须完整保留处理工艺链，包括处理方式（脱脂、酸洗钝化）、执行标准、验收判据（如白绸布检查标准）均纳入同一条目的指标特征字段，不得拆散或简化。

11. **基础安装参数抽取规则**：地脚螺栓规格/数量、基础底板尺寸、预留孔洞三维尺寸及数量、配套螺母/垫圈规格等土建安装接口参数，须按部件分别建立条目，部件字段精确到具体构件名称，覆盖尺寸、数量、规格、配套件四个维度，规格与数量分离抽取，不得合并为单一"安装参数"。

12. **交付与运输状态抽取规则**：充氮压力范围、露点要求、管口封堵状态、保护气体类型等交付与运输保护条件，须分别抽取保护气体类型、压力区间、露点上限、管口封堵方式四项，各自独立成条；运输态与交货态若要求不同应分别记录，不得与正常工作参数混淆。

13. **定性与待确认要求完整保留规则**：对于无具体数值的功能性、合规性描述（如"满足国家及行业规范""清洁度检验方法"），应完整保留原文核心表述作为指标特征，不得简化；外观颜色、LOGO、法兰形式、备品备件等需与甲方协商确定的内容，指标特征字段须明确写明"须与甲方确认"，不得填写假定值，且此类条目不得省略。
