## 一、custom V2 canonical 规则集（consolidation 合并后的唯一一份，15 段）

1. **设备主体识别规则**：以文档标题或首段出现的"容量+介质+设备类型"组合（如"XXm³液氮储罐"）作为设备主体名称，全文所有条目保持一致并统一挂载至各子条目。

2. **整体性能参数归属规则**：凡描述介质、容积、压力、温度、绝热形式、蒸发率、真空寿命、充满率等宏观运行参数的条目，设备部件统一标注为"储罐整体"。

3. **运输/交货状态独立抽取规则**：封存压力、封存气体类型及露点、保护气体类型、管口封堵状态等交付保护要求须作为独立指标条目抽取，指标名称冠以"运输封存-"或"交货状态-"前缀以区分场景，不归入"储罐整体"。

4. **子系统/附件独立成部件规则**：自增压器、安全装置、仪表（压力、液位、真空）、各类阀门、管口等功能性附件，各自独立标注为设备部件，不合并至"储罐整体"。

5. **多部件拆分规则**：当一条原文同时描述多个部件（如内罐/外罐/管道/阀门材料、上进液管/下进液管、多管口并列），须按部件逐条拆分，每条仅对应一个部件，原文字段保留完整原句。

6. **复合指标拆分规则**：同一部件的同一原文若包含多个独立指标维度（如通径+压力等级、规格+数量+备注、RT检测+PT检测），须按指标名称逐条拆分，每条仅含一个指标名称与对应特征，原文字段保留完整原句。

7. **指标名称规范化规则**：同一属性在不同语境下的表述（如"通径""内通径""管口规格"）应统一归类；检测类指标须细分为"检测标准""检测比例""检测技术等级""合格级别"等子指标，不可笼统合并。

8. **管口/接口规格抽取规则**：管口信息优先以原文格式为准（"外径×壁厚"如Φ108×4，或公称通径DN值），不做换算；同时独立抽取"通径（DN值）"与"压力等级（MPa）"两个指标条目。

9. **阀门/仪表清单抽取规则**：设备清单中每项阀门、仪表、附件，分别抽取"规格（DN/PN或精度等级）"与"数量（台/套/支）"为两条独立记录；若有附加说明（如"含配套法兰及紧固件"），额外增加"备注"条目，不混入规格或数量字段。

10. **材料要求分层抽取规则**：内罐、外罐、管道、阀门的材料分别独立成条，指标名称统一为"材料"，不合并描述。

11. **检测标准完整引用规则**：无损检测条目须同时包含执行标准编号（含版本年号）、检测比例、技术等级、合格级别，缺一不可；不同检测方法（如RT/PT）分条记录，不合并。

12. **工艺/结构设计要求抽取规则**：涉及结构设计要求（如防涡装置、液封结构、双阀设置）及无量纲工艺要求（如清洁度处理方式、焊接结构形式）的条款，须独立抽取，指标名称取其核心功能描述，指标特征以完整描述性语句表达，不强行数值化。

13. **限值符号与完整性保留规则**：指标特征中的不等式符号及方向性限定词（≤、≥、不少于、不高于、不低于等）须原样完整保留，不得转换为等值表达；范围值须保留上下限完整表达，不得仅保留数值。

14. **功能性/描述性要求保留原文规则**：对于无具体数值的功能性或描述性要求（如"使用简单方便""远传接口""信号输出"），指标特征字段完整保留原文表述，不截断、不替换为空值或泛化词，指标名称取其核心功能词。

15. **原文溯源保留规则**：每条抽取记录须保留完整原文片段（含原始编号、标点）以支持歧义核查；当原文存在明显OCR错误时，指标特征按语义修正，但原文字段保持原样不改动。
